1. 서비스 개요

언어를 배우는 사람이 책의 문장을 직접 손으로 베껴 쓰고(필사), 보지 않고 다시 떠올려 쓰며(외우기) 익히는 노트. 분량은 한 줄에서 시작해 1줄 → 2줄 → 3줄 → 4~9줄 → 한 페이지로 늘려 간다. 모르는 단어는 뜻과 함께 메모패드에 적는다.

  • 근거(가설): 읽기만 반복하는 것보다 스스로 떠올려 쓰는 인출 연습이 기억에 더 오래 남는다 (Karpicke & Roediger 2008, Science).
  • 앱이 해 주지 않는 것: 자동 번역, 사전, 발음, 문법 설명. 해석과 단어 뜻은 사용자가 직접 적는다.

2. 화면 구조

화면 내용
노트 필사 + 외우기 펼침면, 단어 · 뜻 메모패드, 외우기 기록 회차
일 날짜별 필사 목록
주 · 월 필사한 날과 줄 수를 달력으로 보기
통계 필사 횟수, 줄 수 추이, 외움 비율
서재 책 목록, 책 추가 · 수정
검색 문장 · 해석 · 단어 · 뜻 · 책 이름 · 외우기 기록

위쪽에는 책마다 포스트잇 인덱스 탭이 붙고, 탭은 이동만 한다. 인덱스와 날짜 · 쪽수 태그 사이는 충분히 띄우고 "인덱스 : 책" 라벨은 두지 않는다.

3. 노트 화면

3-1. 새 필사 (책 미선택 회색)

  • [+ 새 필사]는 인덱스로 이동하지 않고 빈 새 페이지가 그대로 열린다.
  • 책을 고르기 전까지 페이지는 회색이고, 문장 · 해석 칸과 [외우기 시작]이 잠긴다.
  • 인덱스 탭을 누르거나 왼쪽 위 책 선택에서 책을 고르면 그 책의 색으로 바뀌고 잠금이 풀린다. 쪽수는 그 책의 마지막 필사 쪽수로 채워진다.
  • 책이 없다면 책 선택에서 [+ 책 추가]로 바로 만들 수 있고, 만든 책은 지금 페이지에 연결된다.
  • 아무것도 쓰지 않고 다른 곳으로 가면 빈 페이지는 자동 삭제된다.

3-2. 왼쪽: 필사

  • 책 선택 · 날짜 · 쪽수(p.N) 한 줄, 아래에 필사할 문장 입력.
  • 해석(선택): 문장 바로 아래, 사용자가 편한 언어로 적는다. 비워 둬도 된다. 외우기 중에도 보인다.
  • 분량 사다리와 다음 분량 안내(nudge): 한 줄에서 시작해 다음 단계로 올려 가도록 권한다.
  • 입력은 즉시 자동 저장.

3-3. 오른쪽: 외우기

  • "{언어} 문장 자체 외우기": 문장을 가리고 처음부터 떠올려 쓴다. 시도마다 처음부터 다시 쓴다.
  • Enter = 다음 시도, Shift+Enter = 줄바꿈, Ctrl/⌘+Enter = 확인하기. 한글 조합 중 Enter는 무시한다(IME 보호).
  • 채점: 대소문자 · 문장부호를 무시하고 단어 단위로 비교(한중일은 글자 단위). 일치한 부분과 놓친 부분을 색으로 보여 준다.
  • 상태: 외우기 전 / 외우는 중 / 외움(한 번이라도 완전 일치).

3-4. 단어 · 뜻 메모패드

  • 필사 · 외우기 펼침면 아래, 외우기 기록 회차 위에 노란 메모지로 놓인다.
  • [+ 단어 추가] → 단어와 뜻을 한 줄씩. 즉시 저장, 줄별 삭제.
  • 단어와 뜻이 모두 빈 줄은 화면을 떠날 때 정리된다.

3-5. 외우기 기록 회차

메모패드 아래에 회차별 시도 횟수와 결과가 나열된다. 삭제하면 8초 동안 실행 취소 토스트가 뜬다.

3-6. 책 정보

  • 필사 화면의 [책 정보]에서 보기 · 수정: 책 이름, 저자, 언어, 총 쪽수, 메모.
  • 인덱스 아래에 한 줄 요약: 윌리엄 셰익스피어 · 영어 · 총 300쪽 중 p.54 (18%). 책을 고르기 전에는 안내 문구가 나온다.
  • 저자 · 총 쪽수 · 메모는 비워도 된다.

4. 일 · 주 · 월

날짜를 누르면 그날의 필사 목록으로 간다. 필사한 날은 표시되고, 월 화면에서는 줄 수가 늘어나는 흐름을 볼 수 있다.

5. 서재 · 검색 · 통계

  • 서재: 책 카드, 책 추가 · 수정 · 삭제. 책 색은 자동 배정.
  • 검색: 문장 · 해석 · 단어 · 뜻 · 책 이름 · 외우기 기록.
  • 통계: 필사 횟수, 줄 수 추이, 단어 메모 수, 외움 비율.

6. 데이터 모델

Book   { id, title, author?, lang, color, total?, memo? }
Entry  { id, book | "" (미선택), date, page?, text, tr?, vocab: [{ w, m }], recalls: Recall[] }

저장은 브라우저 localStorage(pilsa.v1). 계정 · 서버 동기화는 후속.

7. 엣지 케이스

상황 동작 상태
책 미선택 새 필사 회색, 문장 · 해석 · 외우기 잠김 정함
아무것도 안 쓴 새 필사 이동 시 자동 삭제 (책만 고른 경우 포함) 정함
책 선택 후 쪽수 비어 있음 그 책의 마지막 쪽수로 채움 정함
단어 · 뜻 모두 빈 줄 화면을 떠날 때 정리 정함
같은 단어 중복 막지 않음 임시
쪽수가 총 쪽수 초과 진행 %는 100%까지만 표시 임시
책 삭제 그 책의 필사 처리 방식 미정
해석 칸 언어 지정 없음, 안내 문구만 미정
